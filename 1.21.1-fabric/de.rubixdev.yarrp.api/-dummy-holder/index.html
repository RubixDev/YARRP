class DummyHolder<T>(key: ResourceKey<T>) : Holder<T>

A dummy implementation of Holder to help with RuntimeResourcePack creation.

Since Minecraft 1.21.5, the armor trim smithing recipe builder takes an additional argument for the actual pattern to apply, but in the form of a Holder, which is only really handed out by registries. We cannot really access the vanilla registries during RRP serialization though, but we also don't actually need to, since only the ResourceKey is actually required for serialization. This type allows us to do precisely that, acting as a Holder without a value behind the key.
